# iOS 悬浮圆点模式设计

日期：2026-07-31
状态：已确认（用户逐项确认后批准）

## 目标

为 EmbedQuickRef 增加"悬浮圆点"交互模式（类似 iOS 辅助触控 / 迅雷悬浮窗）：桌面常驻一个带光晕的半透明小圆点，点击展开主界面，失焦自动缩回。悬浮模式成为默认，现有弹窗/固定模式保留为设置选项。

## 已确认的需求决策

1. **模式关系**：悬浮成为默认模式；弹窗（失焦隐藏）、固定（置顶+任务栏）保留为设置选项
2. **失焦行为**：展开态失焦 0.2s 后自动缩回圆点；圆点态常驻桌面（失焦不消失）
3. **外观**：iOS 辅助触控风格——64px 半透明深蓝灰正圆 + 白色细边 + 多层外发光光晕
4. **展开状态**：总是回到搜索页，焦点落搜索框
5. **实现方案**：单窗口形态切换（圆点态 64×64 ↔ 展开态 680×500），瞬开瞬收无动画

## 架构

### 窗口形态状态机

```
compact（圆点态）  --点击圆点/热键/托盘-->  expanded（展开态）
expanded           --失焦/Esc(二次)/热键/托盘-->  compact
```

- 单窗口 `main` 复用；形态切换 = `setSize` + 窗口内容切换
- 圆点态：64×64、透明、置顶、跳过任务栏；运行时 `setMinSize(64,64)`（绕过 conf 的 520×300 下限）
- 展开态：680×500、透明 + Acrylic；`setMinSize(520,300)` 恢复
- 展开位置：窗口左上角对齐圆点左上角（就地展开），超出屏幕自动纠正回可见区域
- 圆点位置持久化到 `state.json`（`dotPosition: {x, y}`），重启恢复

### 界面模式（设置面板三选一）

| 模式 | 启动形态 | 失焦行为 | 任务栏 |
|---|---|---|---|
| floating（默认） | 圆点态 | 展开态→缩回圆点 | 隐藏 |
| popup（现有弹窗） | 展开态 | 隐藏窗口 | 隐藏 |
| pinned（现有固定） | 展开态 | 不隐藏 | 显示 |

- 模式选择持久化 `state.json`（`mode` 字段），重启生效
- 三种模式共享全部现有功能（搜索/标签页/AI/历史/设置）

### 圆点组件（新增 FloatingDot.vue）

- 64px 正圆：`rgba(35,48,66,0.82)` 半透明背景 + 白色细边框（1px rgba 白 0.35）+ 内高光（inset 阴影）+ 外发光光晕（多层 box-shadow，最外层 0 0 24px rgba(82,112,143,0.55)）
- 悬停：scale(1.06) + 光晕增强；按下：scale(0.94)，0.15s 过渡
- 交互：
  - 左键单击 → 展开（事件 `@expand`）
  - 左键按住拖动 → `startDragging`（复用现有拖动手柄机制；点击与拖动由系统拖拽语义天然区分）
  - 右键 → 原生菜单（展开/设置/退出），复用现有 `Menu` API 与托盘菜单一致的项
- 圆点态下 `.content` 区域隐藏，仅渲染圆点层；body/壳背景全透明

### App.vue 改动

- 新增形态状态：`form = ref("compact" | "expanded")`、`mode = ref("floating" | "popup" | "pinned")`
- 形态切换函数：
  - `enterCompact()`：`setMinSize(64,64)` → `setSize(64,64)` → 记录当前位置（用于就地展开）→ 切 form
  - `enterExpanded()`：`setMinSize(520,300)` → `setSize(680,500)` → 纠正位置到可见区 → 切 form → `view="search"` → 聚焦搜索框
- 失焦策略改造（现有 `onFocusChanged` + `hideTimer`）：
  - floating 模式：展开态失焦 → `enterCompact()`；圆点态失焦 → 忽略
  - popup 模式：维持现有隐藏逻辑
  - pinned 模式：维持现有不隐藏
- 热键 `toggleWindow()`：floating 模式下 = 形态切换；popup/pinned 维持现有
- 托盘菜单"显示/隐藏"：floating 模式下 = 形态切换
- Esc 逻辑：展开态下先退回搜索（现有），搜索态再 Esc → 缩回圆点（floating 模式）
- 启动（onMounted）：读 `mode` 持久化 → floating 则 `enterCompact()` + 恢复圆点位置；否则维持现有行为
- 拖动结束保存圆点位置：拖动中监听窗口 `onMoved` 或拖动后 `outerPosition` 写入 state（防抖）

### SettingsPanel.vue 改动

- 新增"界面模式"分组：悬浮 / 弹窗 / 固定 三选一单选组，保存后写入 state（重启生效提示）
- 模式切换为浮动时若当前为展开态，立即缩为圆点态（即时反馈）

### lib.rs / 配置改动

- 不需要新增窗口；`tauri.conf.json` 的 minWidth/minHeight 保留 520×300，运行时由前端 setMinSize 控制
- 无 Rust 侧逻辑变更（复用现有 API 权限）

## 边界与错误处理

- `setSize`/`setMinSize`/`setPosition` 失败：catch 静默，重试一次，不阻塞交互
- 显示器变化导致圆点位置在屏幕外：展开前用 `availableMonitors` 计算，纠正到可见区域
- 圆点位置恢复时同样做可见性纠正
- 单实例二次启动（悬浮模式）：`show()` 主窗口并展开（现有 single-instance 回调基础上补 `enterExpanded` 语义：悬浮模式下展开而非仅 show）

## 验证计划

1. CDP 全链路：圆点态 DOM（仅圆点层）、点击展开（尺寸 680×500 + 搜索视图 + 输入框聚焦）、失焦缩回（尺寸 64×64 + 圆点层）、热键切换、Esc 两级行为
2. 窗口级验证：GetWindowRect 检查尺寸；位置记忆（拖动后重启恢复）；边缘吸附
3. 设置面板：三模式切换即时生效、重启后模式保持
4. 回归：弹窗/固定模式行为不回归（失焦隐藏/置顶+任务栏）

## 不做的事（YAGNI）

- 不做展开/收起动画（瞬切，与 iOS 辅助触控一致）
- 不做贴边自动滑出/滑入动画（仅简单边缘吸附）
- 不做多显示器专属策略（仅可见区纠正）
- 不改动搜索/AI/历史等业务功能
